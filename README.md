# TwinFinish Painting & Tiling — Website Concept Pack

This pack contains a complete responsive website concept for **TwinFinish Painting & Tiling**, led by Frank Sbu Biyela, plus desktop/mobile image assets, brand files, page copy, prompts and rendered mockups.

## Open the website mockup
Open `SOURCE/index.html` in a browser. For the most reliable local navigation, run a simple local server from the SOURCE folder, for example `python -m http.server 8000`, then open `http://localhost:8000`.

## What is included
- `SOURCE/` — working multi-page responsive HTML/CSS/JS mockup
- `MOCKUPS/overview-board.png` — one-page presentation overview
- `MOCKUPS/desktop/` — full-page desktop screenshots
- `MOCKUPS/mobile/` — full-page mobile screenshots
- `ASSETS/desktop/` and `ASSETS/mobile/` — responsive hero and section assets
- `ASSETS/gallery/` — project concept imagery
- `ASSETS/contact-hero-master.png` — the uploaded contact representative photo with only the requested TwinFinish branding overlays on the wall, shirt and cup
- `ASSETS/social/facebook-poster.png` — Facebook poster
- `BRAND/` — logo files, favicon and palette
- `CONTENT/` — page structure, copy, launch checklist and missing business information
- `PROMPTS/` — OpenCode master build prompt, future image prompts and design system notes
