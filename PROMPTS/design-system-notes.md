# TwinFinish design system notes

## Palette
- Deep Navy: #061729
- Secondary Navy: #0B2844
- TwinFinish Orange: #FF7A00
- Warm Orange: #FF9A2B
- Paper: #F6F7F8
- Ink: #0A1724
- Muted: #667383

## Visual rules
- Navy frames the brand; orange is a conversion/accent colour, not a full-page background everywhere.
- Keep hero text large, tight and editorial.
- Use white/light sections between dark immersive sections to create rhythm.
- Border radius: 18–30px depending on component scale.
- Motion: 200–500ms, purposeful, respect prefers-reduced-motion.
- Avoid generic contractor clichés such as excessive paint splashes, hazard stripes, fake review counters and stock-photo handshakes.
